# Fullstack Social Media Platform (Spring Boot + React)

Полнофункциональное веб-приложение (Single Page Application), представляющее собой платформу для публикации постов и общения пользователей. Проект демонстрирует интеграцию современного Java-бэкенда с реактивным фронтендом и безопасной системой аутентификации.

---

## 🛠 Технологический стек

### Backend:
* **Framework:** Spring Boot (Web, Data JPA)
* **Security:** Stateless Auth с использованием **JWT (JSON Web Tokens)**
* **Validation:** Hibernate Validator (JSR 303)
* **Database:** MariaDB / MySQL
* **Tools:** Maven, Auth0 JWT Library

### Frontend:
* **Library:** React 18
* **Routing:** React Router v6
* **API Client:** Axios
* **State Management:** React Hooks (useState, useEffect)

---

## 🚀 Ключевые особенности и архитектура

### 1. Безопасность на базе JWT
* Реализована **Stateless-аутентификация**: сервер не хранит состояние сессии, обмениваясь с клиентом зашифрованными токенами.
* Реализован `JwtService` для генерации и верификации токенов на основе алгоритма **HMAC256**.
* На фронтенде реализован `ProtectedRoute` для ограничения доступа к приватным роутам (создание постов, личный кабинет).

### 2. REST API Design
* Разработана архитектура эндпоинтов для управления ресурсами:
    * `GET /api/posts` — получение ленты постов (с сортировкой на стороне БД).
    * `POST /api/users` — регистрация с кастомной валидацией (проверка уникальности логина).
    * `POST /api/jwt` — выпуск токена при входе.
    * `POST /api/posts` — создание контента с привязкой к авторизованному пользователю.

### 3. Современный Frontend (SPA)
* **Component-Based Architecture:** Приложение разделено на переиспользуемые компоненты (Header, Middle, PostDetail и др.).
* **Dynamic Content Loading:** Загрузка данных через Axios без перезагрузки страницы.
* **Client-side Routing:** Использование `react-router-dom` для навигации, обработки параметров (например, `/posts/:id`) и отображения 404 страниц.

### 4. Валидация и обработка ошибок
* Двухуровневая валидация:
    1. На фронтенде для мгновенного фидбека пользователю.
    2. На бэкенде через `@Valid` и кастомные `Validator` классы (`UserCredentialsRegistrationValidator`) для обеспечения целостности данных.

---

## 📋 Функционал приложения
* **Система постов:** Создание и просмотр ленты постов в реальном времени.
* **Аутентификация:** Регистрация, логин и автоматический вход при наличии валидного JWT в `localStorage`.
* **Личный кабинет:** Просмотр списка пользователей и управление собственным контентом.
* **UX/UI:** Интерактивные формы, обработка событий клавиатуры (Enter в хедере), адаптивная навигация.
